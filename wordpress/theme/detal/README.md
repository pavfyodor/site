# Деталь 1.3 — карточки каталога с 3D-графикой

Оригинальный набор: главный баннер и 6 изображений категорий (фильтры, масла/жидкости, тормоза, подвеска/рулевое, электрика, аксессуары/инструменты). WebP сохраняет прозрачность категорий. Исходные генерации хранятся отдельно от архива темы.

Изображения категорий автоматически подбираются по их названию или slug на русском/английском. Для неизвестной категории используется стандартное изображение WooCommerce. На главной показаны все корневые категории, включая пустые; стандартная категория WooCommerce «Без категории» исключена. Товары, категории, остатки, цены, фотографии товаров, заказы и настройки сайта обновление темы не изменяет.

Установка обновления: WordPress → Внешний вид → Темы → Добавить новую тему → Загрузить тему → выбрать ZIP → Установить → Заменить текущую тему загруженной. Используется та же папка темы detal. Если ранее вручную редактировали файлы установленной темы, сначала сохраните их копию. После установки при необходимости очистить кеш хостинга/плагина и обновить страницу браузера.

Проверено на локальном WordPress/WooCommerce: PHP lint, загрузка баннера и всех шести изображений, 7 существующих товаров, AJAX-корзина, отсутствие горизонтальной прокрутки при 390/768/1440 px, отсутствие ошибок JavaScript. Публикация ZIP не устанавливает обновление на пользовательский хостинг.


## Обновление 1.3

Категории представлены карточками с названием, пояснением, 3D-иллюстрацией на подиуме и кнопкой «Смотреть товары». Вся карточка — одна ссылка на реальный архив категории, вложенных кнопок/ссылок нет. Карточки доступны с клавиатуры. На компьютере 3 столбца, на телефоне 2, на экранах уже 360 px — 1.

Если разделов ещё нет, после установки обновления откройте «Внешний вид → Темы» и нажмите «Добавить разделы каталога» в уведомлении «Деталь». Это явное действие администратора с правом manage_woocommerce, защищённое nonce; создаёт только отсутствующие разделы: Фильтры, Масла и жидкости, Тормозная система, Подвеска и рулевое, Электрика, Аксессуары. Уже существующие категории и товары не изменяются. Само обновление файлов не создаёт записи в базе.

Проверки 1.3: шесть разных ссылок на категории, шесть подписей/CTA/изображений, переход в категорию, PHP lint, отсутствие горизонтальной прокрутки при 320/390/768/1440 px и ошибок JavaScript.
