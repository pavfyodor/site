# Деталь

Адаптивная демонстрационная витрина автозапчастей на HTML, CSS и JavaScript. Сборка и установка npm-зависимостей не нужны. Требуется Python 3 для локального HTTP-сервера.

## Запуск

```sh
cd /workspace/site
python3 -m http.server 3000 --bind 0.0.0.0
```

Проверка: `curl -fsS http://127.0.0.1:3000/`. Проверка синтаксиса: `node --check app.js`.

Реализованы поиск по названию, бренду и артикулу, категории, сортировка, избранное и корзина (localStorage). Форма автомобиля сохраняет выбор на странице, но не проверяет совместимость. Остатки, цены и ассортимент демонстрационные. Серверная часть, оплата, реальные контакты и оформление заказов не подключены. Manrope загружается из Google Fonts при доступности; есть системный шрифт для автономной работы.
